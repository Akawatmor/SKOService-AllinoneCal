# SKOService-AllinoneCal

An all-in-one calculator suite built with Next.js and Tailwind CSS, optimized for Bun.

## Features

- **Unit Converter**: Comprehensive unit conversion tool with **15 categories** and **200+ units**:
  - **Length**: Metric (nm to km), Imperial (thou to miles), Thai (นิ้ว, ศอก, วา), Nautical, Astronomical (AU, light-years, parsecs)
  - **Mass/Weight**: Metric, Imperial, Thai (สลึง, บาท, ชั่ง, เกวียน), Troy ounces, Carats
  - **Volume**: Metric, US/UK Imperial, Thai (ทะนาน, ถัง), Cubic measurements
  - **Area**: Metric, Imperial, Thai (ตารางวา, งาน, ไร่)
  - **Speed**: m/s, km/h, mph, knots, mach, speed of light
  - **Time**: Nanoseconds to millennia
  - **Temperature**: Celsius, Fahrenheit, Kelvin, Rankine, Réaumur
  - **Force**: Newtons, dynes, kgf, lbf, kips
  - **Pressure**: Pa, bar, atm, psi, mmHg, torr
  - **Energy**: Joules, calories, kWh, BTU, eV
  - **Power**: Watts, horsepower, BTU/h
  - **Light**: Lumens, candelas, lux, foot-candles
  - **Angle**: Degrees, radians, gradians, arcminutes
  - **Frequency**: Hz to THz, rpm, rad/s
  - **Substance Amount**: Moles, millimoles, kilomoles

- **Periodic Table**: Interactive periodic table with **118 elements**:
  - Detailed element information (atomic mass, electron configuration, properties)
  - Bilingual support (English/Thai names)
  - Molar mass calculator for chemical formulas
  - Color-coded by element categories
  - Search functionality

- **Value for Money**: Compare products with quantity per pack to find the cost-effective option.
- **Chain Calculator**: Perform continuous step-by-step calculations with annotations.
- **CAS (Computer Algebra System)**: Powerful symbolic mathematics using Giac WASM.
- **Base Converter**: Convert numbers between different bases (2-36) including Binary, Octal, Decimal, and Hexadecimal.
- **Date Calculator**: Calculate date differences or add/subtract time periods with precision.
- **Storage Converter**: Convert between bits, bytes, and all storage units (KB, MB, GB, KiB, MiB, GiB, etc.).

## Tech Stack

- **Framework**: Next.js 14+ (App Router)
- **Runtime**: Bun
- **Styling**: Tailwind CSS
- **Icons**: Lucide React

## Getting Started

1. Install dependencies:
   ```bash
   bun install
   ```

2. Run the development server:
   ```bash
   bun run dev
   ```

3. Open [http://localhost:3000](http://localhost:3000) with your browser.

## Mobile Use

This application is designed with a "Mobile-First" approach, making it ideal for use on smartphones.
